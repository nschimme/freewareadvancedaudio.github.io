# Freeware Advanced Audio Organization

Welcome to the official website repository for **Freeware Advanced Audio** (FAAC & FAAD2).

## Features
- **FAAC 2.0+**: Complete LGPL v2.1+ rewrite of the AAC encoder. Clean ISO-free codebase, fast performance, and HE-AAC v1 support.
- **FAAD2**: GPL v2+ AAC/HE-AAC/M4A decoder library.
- **WASM Playground**: In-browser AAC audio encoding and decoding demonstration powered by WebAssembly.
- **VitePress Documentation**: Developer C API guides, CLI reference, and news/blog posts.

## Development

```bash
# Install dependencies
npm install

# Run local development server
npm run docs:dev

# Build static production site
npm run docs:build
```
