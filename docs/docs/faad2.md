# FAAD2 Decoder Overview & Licensing

**FAAD2 (Freeware Advanced Audio Decoder)** is an open-source MPEG-2 and MPEG-4 AAC audio decoder library (`libfaad`) and command-line tool (`faad`).

<span class="badge-gpl">GPL v2+ Licensed</span>

---

## Capabilities & Profiles

FAAD2 provides robust decoding support across all common AAC object types and profiles:

- **Object Types**: LC (Low Complexity), Main, LTP, LD, ER, SBR (Spectral Band Replication), PS (Parametric Stereo).
- **Profiles**: HE-AAC v1 (AAC LC + SBR) and HE-AAC v2 (AAC LC + SBR + PS).
- **Containers**: MP4, M4A, ADTS, and Raw AAC bitstreams.
- **Multichannel**: Full multichannel decoding (up to 7.1 surround sound).
